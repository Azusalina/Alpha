# 非断言文本与证据策略 v2

这是本机、可审计的规则策略，不是通用语义理解、人格测量或心理诊断。
`translator/discourse.py` 与 `model/evidence.py` 对新预览及首次拟合使用
`assertion-guards-v2`；不会重算已经提交过的拟合。

## 断言与非断言

| 原文例子 | 默认价值提取 |
| --- | --- |
| 我重视公平。 | 公平正向支持 |
| 我不重视公平。 | 公平负向支持 |
| 我认为自由比安全重要。 | 自由正向支持，不推断安全负向 |
| 我重视“公平”。 | 允许短概念引号 |
| 我重视公平吗？ | 暂不提取：`question` |
| “我重视公平。” | 暂不提取：`quoted_text` |
| 如果我重视公平，我就会做不同的选择。 | 暂不提取：`hypothetical` |
| 朋友说：我重视公平，但我重视自由。 | 暂不提取：`reported_speech` |
| 我觉得公平可能重要。 | 暂不提取：`hedged_value` |
| 我不认为公平不重要。 | 暂不提取：`ambiguous_negation` |
| 我认为自由不比安全重要。 | 暂不提取：`ambiguous_comparison` |
| 我觉得她把自由看得很重要。 | 暂不提取：`other_subject_value` |
| 我认为她的安全很重要。 | 安全正向支持：他人是价值对象，不是观点主体 |
| 对我来说，安全重要。 | 安全正向支持 |
| 我觉得对她来说自由重要，但对我来说安全重要。 | 只提取自身的安全支持 |

引号、反引号代码、Markdown `>` 引述、部分嵌套／未闭合引号有保护。
聊天按指定发言者每一行独立处理；别人的未闭合引号不会覆盖用户自己的下一行。
假设／转述框架可跨逗号延续，到句末、换行或本条用户消息边界停止。
因此混合表达可能少提取，需要用户纠错；没有完整语法、反讽或任意主体解析。

v2 增加有界的他人价值主体保护：识别部分常见代词／关系称谓的“重视／认为”、
“把…看得重要”、“对她来说／在她看来”等框架，不把他人的立场自动计入自我模型。
不会仅因出现他人就丢弃价值，也不会因他人价值框架抑制作者自己的情绪或联系意向。
显式“对我来说／在我看来”可在逗号后延续或重新声明自身观点，到句末／换行／聊天
消息边界停止；引号里的自身观点声明不能越过保护范围。疑问、假设、转述等保护仍生效。
这不是完整语法分析或人名识别：任意姓名、关系从句、混合主体和价值接收者歧义仍有缺口。

原始 `translation.cues` 仍保留词语和位置，不等于已经确认其含义。
问题、引述、转述、假设中的情绪／意向候选也会被抑制；
“我对朋友很失望”的自身表达仍保留。带“可能”的情绪／意向可保留为
`certainty=hedged` 的文本候选，不是已发生事实或测得心理状态。

## 前端可读取的解释

新生成的 `preview.interpretation`、首次拟合的结果及保存的 `fit_context` 包含：

- `evidence_policy="assertion-guards-v2"`：当前提取策略版本。
- `withheld_values`：最多 64 条被基础价值规则暂不采纳的原文片段；
  每条含 `reason`、`parameters`、`evidence`、`span`。
- `withheld_count`：实际暂不采纳的片段总数，不是被忽略的参数总数。
- `withheld_truncated`：是否只截短了诊断列表；不表示只分析了前 64 段。

`span` 仍按原文 Unicode 码点，零起点、右端不含；emoji／CRLF 不规范化。
机器契约见 [`api.schema.json`](api.schema.json) 的 `$defs.interpretation`。

这些字段只描述**基础价值提取规则**的上述保护；不是所有遗漏的穷尽说明，
不列举全部情绪候选抑制，也不等于最终 effects、rank abstain 或临床风险。
主题不匹配、句内证据冲突等其他原因仍可能使 effects 为空。

显式本次参数纠正，以及两份已同意完整原句支持的窄范围纠正复用，
可覆盖基础规则。因此 `withheld_values` 可与同一参数的最终 effect 同时存在。
前端应区分“自动提取暂不采纳”与“用户显式纠正后使用”，不要据此删除 effect。
整份双 true 或 exclamation 仅授权材料拟合，不自动确认每句的语义；
零参数 effect 的材料也可能增加个人词汇计数。

## 历史兼容与验证范围

机器契约保留 `assertion-guards-v1`；`other_subject_value` 只属于 v2，不能将新诊断
伪装成 v1。旧冻结上下文可能没有这些新增字段，极早期还可能标注
`legacy_context_unavailable=true`；不要补造新策略版本或诊断。
再次同意恢复原贡献和原上下文，不静默重新解释。预览中的原始词汇报告
可由当前 translator 生成，而恢复所投影的参数／解释仍是冻结版本。
F6 可在撤回活动贡献后编辑来源，并清除该来源旧冻结拟合及解释历史；之后首次拟合
使用新正文。删除可用于任意状态。其他来源的冻结贡献／解释不重写，通用依赖重放仍待办。

`tests/test_expression_coverage.py` 有 14 项合成回归测试，覆盖上述例子、
聊天隔离、证据位置、诊断上限、显式纠正与旧拟合恢复。
`tests/test_subject_ownership.py` 另有 9 项主体归属回归，覆盖正／负价值、自身情绪、
聊天边界、诊断上限、显式纠正覆盖以及旧 v1 拟合撤销／恢复保持冻结。它们证明规则行为，
不证明杂乱真实日记覆盖率、人格效度或选择预测准确率。
仍需独立标注的真实材料，再决定哪些遗漏值得引入本地 NLP／LLM。
